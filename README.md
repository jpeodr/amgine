# Máquina Enigma

A Máquina Enigma foi um equipamento eletromecânico de criptografia utilizado principalmente pela Alemanha durante a Segunda Guerra Mundial.

Seu funcionamento era baseado em substituição de letras através de rotores internos que mudavam de posição a cada tecla pressionada, fazendo com que a criptografia fosse diferente o tempo todo.

O processo funcionava assim:

1. A letra digitada passava pelos rotores.
2. O sinal era alterado diversas vezes.
3. O refletor devolvia o sinal pelo caminho inverso.
4. Uma nova letra era gerada como saída.

Como os rotores giravam constantemente, a mesma letra podia gerar resultados diferentes em momentos diferentes da mensagem.
